# InternSync | Enterprise Internship & PPO Automation Ecosystem

InternSync is an enterprise-grade platform designed to streamline and automate the complete internship and placement lifecycle between universities and corporate partners. It bridges the gap between academic performance and corporate hiring through an automated verification and tracking pipeline.

## 🚀 Key Features
* **AI Risk & Readiness Predictor:** Automatically classifies student performance into risk/readiness tiers (*Top PPO Material*, *Stable Performer*, *High Risk / Lagging*) based on academic CGPA, aptitude, coding score, and task progress.
* **AI Automated Internship Passport:** Generates a verified digital credential for students upon HR approval.
* **Role-Specific 24-Week Task Engine:** Customized milestone tracking for AI Engineers, Backend Developers, Data Analysts, and Frontend Developers with manual selection and bulk "Select All" features.
* **Automated Letters Vault:** Seamlessly manages official Offer Letters, Status Updates, and Full-Time PPO notifications via an interactive enterprise preview system.

## 🛠️ Tech Stack
* **Backend:** FastAPI, Python, Pydantic, Uvicorn
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla), FontAwesome
